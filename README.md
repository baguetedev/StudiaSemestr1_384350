# CzarneDziurySphinx
Projekt ten jest poświęcony zagadnieniom związanym z czarnymi dziurami. 

## Zawartość
Plik `source` zawiera wszystkie pliki niezbędne do stworzenia dokumentacji w formacie PDF i HTML

## Tematyka
Tekst omawia różne aspekty czarnych dziur, w tym:
- **Definicja czarnych dziur**: Co to jest czarna dziura i jak powstaje.
- **Rodzaje czarnych dziur**: Różne typy czarnych dziur, od czarnych dziur gwiazdowych po supermasywne czarne dziury.
- **Proces formowania**: Jak czarne dziury powstają w wyniku kolapsu grawitacyjnego masywnych gwiazd.
- **Właściwości fizyczne**: Unikalne cechy fizyczne czarnych dziur, takie jak horyzont zdarzeń, osobliwość i promieniowanie Hawkinga.
- **Znaczenie w kosmologii**: Rola czarnych dziur w strukturze i ewolucji Wszechświata
